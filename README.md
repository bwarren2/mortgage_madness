# Mortgage Madness

This repo is for producing analysis of the financials behind mortgages.

Open the notebook on Binder: [![Binder](https://mybinder.org/badge_logo.svg)](https://mybinder.org/v2/gh/bwarren2/mortgage_madness/master?labpath=All%20About%20Mortgages.ipynb)

# Quickstart

```
poetry install
poetry run jupyter lab
```

Binder builds from `requirements.txt` and `runtime.txt`; keep them in step with `pyproject.toml`.
